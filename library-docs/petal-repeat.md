Copies a block of neighbouring rose petals round the rose, with alternate copies mirrored, cells and all, so any source
turns into a whole-petal mandala. Goes after the source; only the rose changes (preset **one-petal-kaleido**).
**mirror** wedges fold by geometry rather than whole petals, and fold the rest of the layer too.

## Params
- repeats: `four` keeps the most variety; `sixteen` repeats one petal, a radial motif.
- petal: 0–15 clockwise from the top; Petal mask's petal N is N − 1 here. Change it when a copy looks flat.
- mirror: off, copies repeat the same way round, a pinwheel.

## Pairings
- After **clouds** or **sparkle**: a drifting mandala, repeated glints.

## Pitfalls
- It reads only 16 / repeats petals: with sixteen, one petal of the source is all that shows.
- A source the same in every petal (an unscattered chase) shows no change.
