The classic xLights chase (marquee, meteors, fills). Sizes are in LEDs, so it crawls on long arches and races on short
spire strands; use **bars** `along` to size to each wire, **in-turn** for groups taking turns.

## Params
- speed: 20 a walk, 60–100 a race on long strands.
- size: Or the room each comet gets. 3–6 marquee bulbs, 10–30 runs, 100+ one comet a strand.
- gap: Bands only; 0.5–0.7 reads as spaced bulbs.
- tail: Comet only; keep below size or tails run into the next comet.
- lap: 50–100 for meteors. In bounce it only changes the scattered starting phase.
- softness: 1–2 crisp but smooth for bands; comets cap it at 1.

## Pairings
- Blend `over` a dim **colour-wash**.
- Then **trails** for a ragged afterglow; **mirror** `along` to chase both ways.

## Pitfalls
- Size above strand length (spire strands 13 LEDs, rose petals 14) flips whole strands; at speed, flashing.
- Alternate is shown for along and bounce; out/in already mirrors each strand.
- Give short-strand groups their own layer and speed.
