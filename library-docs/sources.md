Sources draw one element on transparent, coloured from their `colours` pick. A chain's first source covers; later ones
add unless given a blend. Choose by motion: whole-layer change (colour-wash, clouds), sweeps (bars), along the wires
(single-strand, life, wildfire, waves, fireflies), particles (sparkle, streaks, fireworks, lightning) or the beat
(strobe, heartbeat). Many looks are presets of these.
