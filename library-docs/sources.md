Sources draw: each puts one element (bands, flames, sparks, a spot) on transparent, coloured from its one `colours`
pick, and fills the layer it lands on. A chain's first source covers; later ones add unless given a blend. Choose by
the motion the idea names: a whole-layer change (colour-wash, plasma, clouds), something that sweeps (bars, wave,
lighthouse, curtain), something that runs along the wires (single-strand, arch-chase, life, climb), particles
(sparkle, streaks, ripple, fireworks, lightning, tendril) or a beat (strobe, heartbeat).
